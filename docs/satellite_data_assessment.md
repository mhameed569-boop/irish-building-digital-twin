# Satellite and Earth-observation assessment

## Recommendation: DEFER

The current public Small Area table already contains official urban/rural classification, polygon area and population/housing density. These features cover the immediate baseline need without downloading very large imagery.

Potential later products are Copernicus CORINE Land Cover, European Settlement Map, Urban Atlas (where coverage applies), and Sentinel-derived impervious/built-up products. Scientifically plausible features include built-up share, impervious surface, vegetation share, land-cover diversity and settlement morphology.

Include them only after the authorised actual-energy target and baseline spatial validation are established, and only if ablation tests show added predictive value beyond Census density and urban/rural variables. Prefer precomputed official products over raw Sentinel scenes. Preserve product version, acquisition/reference year, CRS, raster resolution, resampling method, zonal aggregation statistic and no-data coverage. Avoid claiming building-level conditions from coarse land-cover pixels.
